# Add or change a spot

## Where spots live

| What | File | Entry |
|---|---|---|
| Named breaks (map labels, Popular breaks page) | `surfmap/spots.py` `SPOTS` | `("Name", "Region", lat, lon, facing)` |
| Regional page coasts (Lake Michigan, Greece, Peru, …) | `surfmap/regions.py` `REGIONS[region]["coasts"]` | `("Name", "Area", lat, lon, facing[, (label_lon, label_lat)])` |
| Under-the-radar stretches | `surfmap/stretches.py` | generated by `python -m surfmap discover`; rename via `RENAME` in `discover.py`, don't hand-edit |

**`facing`** is the compass direction the break looks out to sea, in degrees (0 = N, 90 = E).
Swell counts when it arrives within the angle setting of `facing` (75° by default), and wind
blowing from `facing + 180` (± 45°) is offshore. Getting `facing` right matters more than
getting the position exactly right. Check it against the coastline: a south-facing point
break like Malibu is 190, Chicago's lakefront is 80.

**Position:** put the point at the break or just off it, in water. Data is read from the
nearest wave-model sea cell a little seaward along `facing`, and the ERA5 wind 0.15° out.

The optional regional label position is a `(lon, lat)` tuple, used where the default label
placement collides with others on the regional map.

## Then

1. **Fetch** its waves (Copernicus, both swell trains) and wind (ERA5). This downloads only
   points that aren't cached yet, so it is quick for one spot:
   `uv run python -m surfmap fetch --source points`.
   - Moving a point changes its coordinates, so it fetches anew. Delete the old
     `data/points/<lat>_<lon>_*.nc` files if you want to tidy up.
   - The tide range comes from EOT20 (`surfmap/tides.py`) and is cached per name in
     `data/eot20/ranges.json`. Delete the entry if a spot moved.
2. **Sanity-check** it with the `check-spot` skill: the share of good mornings by month, and
   which part of the rule fails most.
3. **Rebuild** with `rebuild-pdf` and `publish-atlas`.

## Notes

- In the atlas, a named break within 40 km of a regional coast is drawn once, as the regional
  coast (`DEDUPE_KM` in `export.py`).
- Breaks inside the Great Lakes, Mediterranean, Black Sea or Caspian are judged on total waves
  by the relaxed lake/sea standard, with no wind test (`analysis._basin_of`).
- The user's standing choices: Montara rather than Mavericks; Gaza and Beirut, never Tel Aviv;
  the Lake Michigan town list (Whiting, Gary, Portage, Chicago, Racine, Milwaukee, Sheboygan,
  New Buffalo, St. Joseph, Holland, Grand Haven, Ludington, Frankfort); Kalo Nero and Kastro
  point on the Greece and Mediterranean pages.
